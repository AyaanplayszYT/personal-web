# Personal Portfolio

A basic personal portfolio website made by me as a part of the Stardance mission.
The purpose of this mission was to make a website using HTML and CSS which looked good, responsive, and personal.

## Features

* Adaptive for all screen resolutions
* Simple and clean portfolio structure
* Personal introduction part
* Projects and information parts
* Navigation among different parts
* Social and other links
* Font Awesome icons
* Hover effects and nice styling
* Mobile optimized layout
* Custom CSS styling
